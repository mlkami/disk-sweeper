# disk-sweeper

Windows PC の空き容量を1回の指示で最大化する Claude Code スキル。

長く使っているPCには、tempでもキャッシュでもない場所にゴミが溜まる。更新のたびに旧インストーラを積み続けるアプリ、アンインストール後も残るデータフォルダ、重複した開発ツールの世代。このスキルはそれを探す。

## インストール

```powershell
git clone https://github.com/Slvaus/disk-sweeper.git "$env:USERPROFILE\.claude\skills\disk-sweeper"
```

**クローンしたら Claude Code を再起動する。** 新しいスキルフォルダは再起動しないと認識されない。

更新は `git pull` だけでよい（再起動は不要）。

```powershell
cd "$env:USERPROFILE\.claude\skills\disk-sweeper"; git pull
```

## 使い方

Claude Code で `/disk-sweeper` と入力する。

走査から検証まで一度に通る。**承認なしに何も削除しない。** 全部調べ終えた時点で、削除候補の一覧が1回だけ提示される。項目ごとにサイズと「なぜ消してよいか」の根拠が付くので、そこで選ぶ。

## 実行前に

- **ゲームやアプリを閉じておく。** 開いているとファイルがロックされ、消せる分が減る
- **UACのプロンプトが出る。** `ProgramData` や `Program Files` の下は管理者権限が要る。承認しないとその分は飛ばされる
- 権限確認のプロンプトが何度か出る。読み取りだけの走査なので通してよい

## 実行後

`%USERPROFILE%\disk-sweeper-report-<日付>.md` にレポートが出る。**このファイルを送り返してほしい。** 環境ごとに違うゴミが見つかるので、それを取り込んでスキルを賢くしていく。

中身は、見つけたが判定できなかったもの、判断が分かれたもの、起きた問題の3つ。個人を特定する情報は入らないが、気になる部分は消して構わない。

## 何をしないか

- ブラウザの履歴・Cookie・パスワード・サイトデータには触れない
- 写真・動画・録画・ゲームのセーブとリプレイ・購入物は削除候補に入れない（サイズが大きくても）
- すぐ再生成されるキャッシュは、消しても意味がないので対象外
- 開発環境に触れた場合は、実際にビルドを通して壊れていないことを確認する

## 動作環境

Windows 10 / 11、PowerShell 5.1 以上。
