# disk-sweeper

1回の指示で PC の空き容量を最大化する Claude Code スキル。OS は問わない。

長期間使用した PC では、一時フォルダや通常キャッシュ以外の場所にも不要ファイルが蓄積する（アップデート時に残された旧インストーラー、アンインストール後の残留データフォルダ、ドライブごとに独立したゴミ箱、複数世代残った開発ツール、ドライバーの旧版など）。本スキルはこれらを網羅的に走査・検出する。

## インストール

**Windows**

```powershell
git clone https://github.com/mlkami/disk-sweeper.git "$env:USERPROFILE\.claude\skills\disk-sweeper"
```

**Linux / macOS**

```bash
git clone https://github.com/mlkami/disk-sweeper.git ~/.claude/skills/disk-sweeper
```

**クローン後は Claude Code を再起動する。** 再起動するまで新しいスキルフォルダは認識されない。

更新時は `git pull` を実行するだけで反映される（再起動不要）。

## 使い方

Claude Code で `/disk-sweeper` と入力する。

走査から安全性検証まで一括で実行される。**ユーザーの承認なしにファイルを削除することはない。**
質問は2回だけで、どちらも選択肢から選ぶ形で出る。

1. **開始前**: 対象のドライブ、追加の作業（ドライバーの整理）、触ってほしくないもの（開発環境、ゲーム）を選ぶ。
2. **全調査の完了後**: 削除候補が「ゴミ箱」「ビルド成果物」のようなまとまりで提示されるので、消すものを選ぶ。選ばなかったものは残る。各候補のサイズと削除可能な理由（根拠）は、作業フォルダの `candidates.md` で確認できる。

### 仕組み

1. **測定**: `scan.py` が全ドライブを1回だけ走査し、担当ごとの要約（digest）を書く。
2. **判定**: 担当エージェント4体（開発環境、アプリのデータ、OS、ゲームとユーザーのファイル）が、軽いモデルで並列に、自分の担当の要約だけを読んで候補を返す。読み取り専用。
3. **集計**: 主エージェントが4つの結果をまとめ、根拠を抜き取りで確かめて、承認用の表を1枚にする。

主エージェントが生のファイル一覧を読まないので、時間と使用量が減る。担当ごとに必要な知識だけを渡すので、見落としも減る。

`scan.py` には Python 3.8 以上が要る（標準ライブラリだけで動く）。Python がない環境や、サブエージェントを使えない環境でも、主エージェントが同じ手順を自分で行うので動く。

## 実行前に

- **実行中のゲームやアプリを終了しておく。** 起動中だとファイルがロックされ、削除可能なファイルが減る
- **管理者権限を許可する。** Windows は UAC、Unix 系は `sudo`。承認しない場合は対象の処理がスキップされる
- 権限確認のプロンプトが複数回表示される場合があるが、走査段階は読み取りのみのため許可して問題ない

## 実行後

ホームディレクトリに `disk-sweeper-report-<日付>.md` が出力される。**改善のため、このファイルのフィードバックを求めている。** 環境ごとに異なる不要ファイルを把握し、スキルの検出精度向上に活用する。

特に「判定できなかったもの」のセクションには、未知のファイルパターンが含まれるため有用な情報となる。レポートに個人を特定する情報は含まれないが、気になる記述は手動で削除してから共有して構わない。

## 何をしないか

- ブラウザの履歴、Cookie、パスワード、サイトデータには触れない
- 写真、動画、録画、セーブデータ、購入コンテンツは、サイズに関わらず削除候補に入れない
- 削除後すぐに再生成されるキャッシュは、容量確保の意味が薄いため対象外
- 使用中のドライバーは消さない（接続していない機器のものも含む）。消すのは、どの機器にも使われていない旧版だけ
- 開発環境のファイルを処理した場合は、実際にビルドを実行して環境が破損していないことを確認する

## 開発

`scan.py` のテスト（作り物のフォルダで、二重計上をしないこと、リンクをたどらないこと、担当の振り分けなどを確かめる）:

```
python -m unittest discover -s tests
```
